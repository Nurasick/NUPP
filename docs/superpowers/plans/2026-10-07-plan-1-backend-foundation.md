# Plan 1 — Backend Foundation & Catalog API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Go HTTP service that serves the public, read-only catalog (courses → offerings → assessments → materials → files) from PostgreSQL, with migrations, tests against a real database, an OpenAPI contract, a Docker image and CI.

**Architecture:** Standard-library `net/http` router with small packages: `config`, `db` (pgx pool + embedded goose migrations), `httpx` (JSON envelope, pagination), `storage` (local-disk file store), `catalog` (sqlc queries + handlers), `server` (routing + middleware). SQL lives in `.sql` files; sqlc generates typed Go. `openapi/openapi.yaml` is the API contract and a test validates real responses against it.

**Tech Stack:** Go ≥ 1.24, PostgreSQL 17, pgx/v5, sqlc 1.29 (run via Docker), goose v3, testcontainers-go, kin-openapi, Docker Compose, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-07-plan-1-catalog-api-spec.md` (v2). Where the code below disagrees with the spec, the spec wins — see *Amendments* right below.

## Global Constraints

- Go module path: `github.com/Nurasick/NUPP/api`; `go.mod` declares `go 1.24`.
- All commands run from the `api/` directory unless a step says otherwise.
- PostgreSQL image: `postgres:17-alpine` everywhere (compose, tests).
- Every JSON response uses the envelope `{"data": …, "error": null | {"code": string, "message": string}, "meta"?: {"total","limit","offset"}}` with `Content-Type: application/json`.
- IDs are UUIDs generated by Postgres (`gen_random_uuid()`).
- Pagination: `limit` default 20, values > 100 clamp to 100, < 1 or non-numeric → 400; `offset` default 0, < 0, > 100000 or non-numeric → 400.
- Allowed values — term: `spring|summer|fall`; assessment kind: `midterm|quiz|final|assignment|lab|other`; material type: `questions|solutions|notes|slides|cheatsheet|other`.
- Empty lists serialize as `[]`, never `null`.
- Config comes only from environment variables (`.env` optional in dev). No secrets in source.
- Tests that touch the database use testcontainers (**Docker must be running**). DB tests do not call `t.Parallel()`; each test starts with `testutil.Reset`.
- Errors are wrapped with context: `fmt.Errorf("load course: %w", err)`.
- Commits use conventional commit messages (`feat:`, `test:`, `chore:` …).

## Review Focus

1. **Search text with LIKE wildcards or non-Latin letters** (`%`, `_`, `\`, `Қазақ`) — matched literally, returns 200, never 500. → Task 6 tests.
2. **Out-of-range pagination** (`limit=abc`, `limit=0`, `offset=-1`, `offset=99999999999`) — 400 with error envelope; `limit=1000` clamps to 100; nothing overflows the `int32` passed to SQL. → Task 4 + Task 6 tests.
3. **Malformed or unknown identifiers** (`/materials/not-a-uuid`, a random UUID, upper-case slug `CSCI-151`) — 400 / 404 / 200 respectively, never 500. → Task 6 + Task 7 tests.
4. **Storage keys that escape the root** (`../x`, `/abs`, `a\..\b`, `C:/x`, empty) — rejected with `storage.ErrInvalidKey`. → Task 5 tests.
5. **Empty collections** (no courses, course without offerings, offering without materials) — JSON `[]`, never `null` (the frontend will `.map()` over them). → Task 6 + Task 7 tests.

```go
// Package config reads service configuration from environment variables.
package config

import "errors"

// Config holds everything the service needs at startup.
type Config struct {
	HTTPAddr    string
	DatabaseURL string
	StorageDir  string
	Env         string
}

// Load builds a Config from getenv (normally os.Getenv).
func Load(getenv func(string) string) (Config, error) {
	cfg := Config{
		HTTPAddr:    valueOr(getenv("HTTP_ADDR"), ":8080"),
		DatabaseURL: getenv("DATABASE_URL"),
		StorageDir:  valueOr(getenv("STORAGE_DIR"), "./data/files"),
		Env:         valueOr(getenv("APP_ENV"), "development"),
	}
	if cfg.DatabaseURL == "" {
		return Config{}, errors.New("config: DATABASE_URL is required")
	}
	return cfg, nil
}

func valueOr(value, fallback string) string {
	if value == "" {
		return fallback
	}
	return value
}
```

```go
// RunWithDB starts a throwaway Postgres container, applies migrations, stores the
// pool in *pool and runs the package's tests. Call it from TestMain:
//
//	func TestMain(m *testing.M) { os.Exit(testutil.RunWithDB(m, &testPool)) }
func RunWithDB(m *testing.M, pool **pgxpool.Pool) int {
	ctx := context.Background()

	// Credentials below belong to a disposable container that only lives for this test run.
	ctr, err := tcpostgres.Run(ctx, "postgres:17-alpine",
		tcpostgres.WithDatabase("nupp_test"),
		tcpostgres.WithUsername("nupp"),
		tcpostgres.WithPassword("nupp"),
		tcpostgres.BasicWaitStrategies(),
	)
	if err != nil {
		log.Printf("start postgres container (is Docker running?): %v", err)
		return 1
	}
	defer func() { _ = testcontainers.TerminateContainer(ctr) }()

	url, err := ctr.ConnectionString(ctx, "sslmode=disable")
	if err != nil {
		log.Printf("postgres connection string: %v", err)
		return 1
	}
	p, err := db.Connect(ctx, url)
	if err != nil {
		log.Printf("connect: %v", err)
		return 1
	}
	defer p.Close()
	if err := db.Migrate(ctx, p); err != nil {
		log.Printf("migrate: %v", err)
		return 1
	}

	*pool = p
	return m.Run()
}
```

```go
// Package db owns the PostgreSQL connection pool and schema migrations.
package db

import (
	"context"
	"embed"
	"fmt"
	"io/fs"

	"github.com/jackc/pgx/v5/pgxpool"
	"github.com/jackc/pgx/v5/stdlib"
	"github.com/pressly/goose/v3"
)

//go:embed migrations/*.sql
var migrationsFS embed.FS

// Connect opens a pool and verifies the database is reachable.
func Connect(ctx context.Context, url string) (*pgxpool.Pool, error) {
	pool, err := pgxpool.New(ctx, url)
	if err != nil {
		return nil, fmt.Errorf("create pool: %w", err)
	}
	if err := pool.Ping(ctx); err != nil {
		pool.Close()
		return nil, fmt.Errorf("ping database: %w", err)
	}
	return pool, nil
}

// Migrate applies all pending migrations embedded in the binary.
func Migrate(ctx context.Context, pool *pgxpool.Pool) error {
	migrations, err := fs.Sub(migrationsFS, "migrations")
	if err != nil {
		return fmt.Errorf("open embedded migrations: %w", err)
	}
	sqlDB := stdlib.OpenDBFromPool(pool)
	defer sqlDB.Close()

	provider, err := goose.NewProvider(goose.DialectPostgres, sqlDB, migrations)
	if err != nil {
		return fmt.Errorf("create migration provider: %w", err)
	}
	if _, err := provider.Up(ctx); err != nil {
		return fmt.Errorf("apply migrations: %w", err)
	}
	return nil
}
```

```go
package catalog

import (
	"regexp"
	"strings"

var nonSlugChars = regexp.MustCompile(`[^a-z0-9]+`)

// Slugify turns a course code like "CSCI 151" into a URL slug like "csci-151".
// Course codes are expected to be Latin letters and digits; an empty result
// means the code cannot be used as a slug.
func Slugify(code string) string {
	slug := nonSlugChars.ReplaceAllString(strings.ToLower(code), "-")
	return strings.Trim(slug, "-")
```

```go
// Package httpx holds the JSON response envelope and request-parsing helpers
// shared by every HTTP handler.
package httpx

import (
	"encoding/json"
	"errors"
	"log/slog"
	"net/http"
	"strconv"

	"github.com/google/uuid"
)

const (
	DefaultLimit = 20
	MaxLimit     = 100
	MaxOffset    = 100_000
)

// Envelope is the shape of every JSON response.
type Envelope struct {
	Data  any    `json:"data"`
	Error *Error `json:"error"`
	Meta  *Meta  `json:"meta,omitempty"`
}

// Error describes a failed request.
type Error struct {
	Code    string `json:"code"`
	Message string `json:"message"`
}

// Meta describes a paginated list.
type Meta struct {
	Total  int64 `json:"total"`
	Limit  int   `json:"limit"`
	Offset int   `json:"offset"`
}

func writeJSON(w http.ResponseWriter, status int, body Envelope) {
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(status)
	if err := json.NewEncoder(w).Encode(body); err != nil {
		slog.Error("write json response", "err", err)
	}
}

// OK writes a 200 response with data.
func OK(w http.ResponseWriter, data any) {
	writeJSON(w, http.StatusOK, Envelope{Data: data})
}

// List writes a 200 response with data and pagination meta.
func List(w http.ResponseWriter, data any, meta Meta) {
	writeJSON(w, http.StatusOK, Envelope{Data: data, Meta: &meta})
}

// Fail writes an error response.
func Fail(w http.ResponseWriter, status int, code, message string) {
	writeJSON(w, status, Envelope{Error: &Error{Code: code, Message: message}})
}

// BadRequest writes a 400 with a message safe to show to users.
func BadRequest(w http.ResponseWriter, message string) {
	Fail(w, http.StatusBadRequest, "bad_request", message)
}

// NotFound writes a 404 such as "course not found".
func NotFound(w http.ResponseWriter, what string) {
	Fail(w, http.StatusNotFound, "not_found", what+" not found")
}

// Internal logs err with request context and writes a generic 500.
func Internal(w http.ResponseWriter, r *http.Request, err error) {
	slog.ErrorContext(r.Context(), "internal error", "err", err, "method", r.Method, "path", r.URL.Path)
	Fail(w, http.StatusInternalServerError, "internal", "something went wrong")
}

// Page is a validated limit/offset pair.
type Page struct {
	Limit  int
	Offset int
}

// ParsePage reads ?limit= and ?offset=. Limits above MaxLimit are clamped.
func ParsePage(r *http.Request) (Page, error) {
	page := Page{Limit: DefaultLimit}
	query := r.URL.Query()
	if raw := query.Get("limit"); raw != "" {
		n, err := strconv.Atoi(raw)
		if err != nil || n < 1 {
			return Page{}, errors.New("limit must be a positive integer")
		}
		page.Limit = min(n, MaxLimit)
	}
	if raw := query.Get("offset"); raw != "" {
		n, err := strconv.Atoi(raw)
		if err != nil || n < 0 || n > MaxOffset {
			return Page{}, errors.New("offset must be an integer between 0 and 100000")
		}
		page.Offset = n
	}
	return page, nil
}

// ParseUUID parses a path parameter that must be a UUID.
func ParseUUID(raw string) (uuid.UUID, error) {
	id, err := uuid.Parse(raw)
	if err != nil {
		return uuid.Nil, errors.New("invalid id")
	}
	return id, nil
}
```

```go
package storage

import (
	"context"
	"errors"
	"io"

var (
	ErrNotFound   = errors.New("storage: object not found")
	ErrInvalidKey = errors.New("storage: invalid key")

// Object is an opened stored file. Seeking lets HTTP serve Range requests.
type Object interface {
	io.ReadSeekCloser
}

// Storage saves and opens objects addressed by slash-separated keys such as
// "materials/<material_id>/<file_id>.pdf".
type Storage interface {
	Put(ctx context.Context, key string, r io.Reader) error
	Open(ctx context.Context, key string) (Object, error)
}
```

```go
package storage

import (
	"context"
	"errors"
	"fmt"
	"io"
	"io/fs"
	"os"
	"path/filepath"
	"strings"
)

// Local stores objects as files under a root directory.
type Local struct {
	root string
}

// NewLocal creates root if needed.
func NewLocal(root string) (*Local, error) {
	if err := os.MkdirAll(root, 0o750); err != nil {
		return nil, fmt.Errorf("create storage root: %w", err)
	}
	return &Local{root: root}, nil
}

func (l *Local) path(key string) (string, error) {
	// fs.ValidPath rejects "", "..", leading "/", and empty or "." elements.
	if !fs.ValidPath(key) || key == "." || strings.ContainsAny(key, `\:`) {
		return "", fmt.Errorf("%w: %q", ErrInvalidKey, key)
	}
	return filepath.Join(l.root, filepath.FromSlash(key)), nil
}

// Put writes r to key atomically: a temp file is renamed into place.
func (l *Local) Put(_ context.Context, key string, r io.Reader) error {
	dst, err := l.path(key)
	if err != nil {
		return err
	}
	dir := filepath.Dir(dst)
	if err := os.MkdirAll(dir, 0o750); err != nil {
		return fmt.Errorf("create object dir: %w", err)
	}
	tmp, err := os.CreateTemp(dir, ".upload-*")
	if err != nil {
		return fmt.Errorf("create temp file: %w", err)
	}
	defer os.Remove(tmp.Name()) // no-op after a successful rename

	if _, err := io.Copy(tmp, r); err != nil {
		tmp.Close()
		return fmt.Errorf("write object: %w", err)
	}
	if err := tmp.Close(); err != nil {
		return fmt.Errorf("close temp file: %w", err)
	}
	if err := os.Rename(tmp.Name(), dst); err != nil {
		return fmt.Errorf("move object into place: %w", err)
	}
	return nil
}

// Open returns the object at key or ErrNotFound.
func (l *Local) Open(_ context.Context, key string) (Object, error) {
	p, err := l.path(key)
	if err != nil {
		return nil, err
	}
	f, err := os.Open(p)
	if errors.Is(err, fs.ErrNotExist) {
		return nil, fmt.Errorf("%w: %q", ErrNotFound, key)
	}
	if err != nil {
		return nil, fmt.Errorf("open object: %w", err)
	}
	return f, nil
}
```

```go
import (

	"github.com/Nurasick/NUPP/api/internal/catalog/catalogdb"
```

```go
// CourseSummary is a course in search results.
type CourseSummary struct {
	ID         uuid.UUID `json:"id"`
	Code       string    `json:"code"`
	Slug       string    `json:"slug"`
	Title      string    `json:"title"`
	Department *string   `json:"department"`
}

// AssessmentView is one midterm, quiz, final, etc.
type AssessmentView struct {
	ID     uuid.UUID `json:"id"`
	Kind   string    `json:"kind"`
	Number *int32    `json:"number"`
	Label  *string   `json:"label"`
}

// OfferingView is one run of a course (year + term) with its assessments.
type OfferingView struct {
	ID          uuid.UUID        `json:"id"`
	Year        int32            `json:"year"`
	Term        string           `json:"term"`
	Instructor  *string          `json:"instructor"`
	Assessments []AssessmentView `json:"assessments"`
}

// CourseDetail is a course page.
type CourseDetail struct {
	CourseSummary
	Offerings []OfferingView `json:"offerings"`
}

func toCourseSummary(c catalogdb.Course) CourseSummary {
	return CourseSummary{ID: c.ID, Code: c.Code, Slug: c.Slug, Title: c.Title, Department: c.Department}
}

func toAssessmentView(a catalogdb.Assessment) AssessmentView {
	return AssessmentView{ID: a.ID, Kind: a.Kind, Number: a.Number, Label: a.Label}
}

// buildCourseDetail nests assessments under their offering, keeping the
// order of both input slices. Empty collections become [] in JSON.
func buildCourseDetail(c catalogdb.Course, offerings []catalogdb.Offering, assessments []catalogdb.Assessment) CourseDetail {
	byOffering := make(map[uuid.UUID][]AssessmentView, len(offerings))
	for _, a := range assessments {
		byOffering[a.OfferingID] = append(byOffering[a.OfferingID], toAssessmentView(a))
	}
	views := make([]OfferingView, 0, len(offerings))
	for _, o := range offerings {
		nested := byOffering[o.ID]
		if nested == nil {
			nested = []AssessmentView{}
		}
		views = append(views, OfferingView{
			ID: o.ID, Year: o.Year, Term: o.Term, Instructor: o.Instructor, Assessments: nested,
		})
	}
	return CourseDetail{CourseSummary: toCourseSummary(c), Offerings: views}
}
```

```go
package catalog

import (
	"errors"
	"fmt"
	"net/http"
	"strings"
	"unicode/utf8"

	"github.com/jackc/pgx/v5"
	"github.com/jackc/pgx/v5/pgxpool"

	"github.com/Nurasick/NUPP/api/internal/catalog/catalogdb"
	"github.com/Nurasick/NUPP/api/internal/httpx"
	"github.com/Nurasick/NUPP/api/internal/storage"
)

const maxSearchLen = 100

var likeEscaper = strings.NewReplacer(`\`, `\\`, `%`, `\%`, `_`, `\_`)

// Handler serves the public catalog.
type Handler struct {
	q     *catalogdb.Queries
	files storage.Storage
}

// NewHandler builds a catalog handler.
func NewHandler(pool *pgxpool.Pool, files storage.Storage) *Handler {
	return &Handler{q: catalogdb.New(pool), files: files}
}

// Register adds the catalog routes to mux.
func (h *Handler) Register(mux *http.ServeMux) {
	mux.HandleFunc("GET /api/v1/courses", h.listCourses)
	mux.HandleFunc("GET /api/v1/courses/{slug}", h.getCourse)
}

func (h *Handler) listCourses(w http.ResponseWriter, r *http.Request) {
	page, err := httpx.ParsePage(r)
	if err != nil {
		httpx.BadRequest(w, err.Error())
		return
	}
	search := strings.TrimSpace(r.URL.Query().Get("q"))
	if utf8.RuneCountInString(search) > maxSearchLen {
		httpx.BadRequest(w, fmt.Sprintf("q must be at most %d characters", maxSearchLen))
		return
	}
	pattern := likeEscaper.Replace(search)

	courses, err := h.q.SearchCourses(r.Context(), catalogdb.SearchCoursesParams{
		Query: pattern, RowLimit: int32(page.Limit), RowOffset: int32(page.Offset),
	})
	if err != nil {
		httpx.Internal(w, r, fmt.Errorf("search courses: %w", err))
		return
	}
	total, err := h.q.CountCourses(r.Context(), pattern)
	if err != nil {
		httpx.Internal(w, r, fmt.Errorf("count courses: %w", err))
		return
	}
	items := make([]CourseSummary, 0, len(courses))
	for _, c := range courses {
		items = append(items, toCourseSummary(c))
	}
	httpx.List(w, items, httpx.Meta{Total: total, Limit: page.Limit, Offset: page.Offset})
}

func (h *Handler) getCourse(w http.ResponseWriter, r *http.Request) {
	slug := strings.ToLower(r.PathValue("slug"))
	course, err := h.q.GetCourseBySlug(r.Context(), slug)
	if errors.Is(err, pgx.ErrNoRows) {
		httpx.NotFound(w, "course")
		return
	}
	if err != nil {
		httpx.Internal(w, r, fmt.Errorf("get course %q: %w", slug, err))
		return
	}
	offerings, err := h.q.ListOfferingsByCourse(r.Context(), course.ID)
	if err != nil {
		httpx.Internal(w, r, fmt.Errorf("list offerings: %w", err))
		return
	}
	assessments, err := h.q.ListAssessmentsByCourse(r.Context(), course.ID)
	if err != nil {
		httpx.Internal(w, r, fmt.Errorf("list assessments: %w", err))
		return
	}
	httpx.OK(w, buildCourseDetail(course, offerings, assessments))
}
```

```go
		httpx.BadRequest(w, "invalid file id")
		return

		httpx.NotFound(w, "file")
		return

	if err != nil {
		httpx.Internal(w, r, fmt.Errorf("get material file: %w", err))
		return

		httpx.NotFound(w, "file")
		return

		httpx.Internal(w, r, fmt.Errorf("open stored file: %w", err))
		return

	if !ok {
		ext = ".bin"

	header.Set("X-Content-Type-Options", "nosniff")

	header.Set("Cache-Control", "public, max-age=31536000, immutable")
```

```go
package server

import (
	"log/slog"
	"net/http"
	"runtime/debug"
	"time"

	"github.com/Nurasick/NUPP/api/internal/httpx"
)

type statusRecorder struct {
	http.ResponseWriter
	status int
}

func (s *statusRecorder) WriteHeader(code int) {
	s.status = code
	s.ResponseWriter.WriteHeader(code)
}

// Unwrap lets http.ResponseController reach the underlying writer.
func (s *statusRecorder) Unwrap() http.ResponseWriter { return s.ResponseWriter }

func logRequests(logger *slog.Logger, next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		start := time.Now()
		rec := &statusRecorder{ResponseWriter: w, status: http.StatusOK}
		next.ServeHTTP(rec, r)
		logger.InfoContext(r.Context(), "request",
			"method", r.Method,
			"path", r.URL.Path,
			"status", rec.status,
			"duration_ms", time.Since(start).Milliseconds(),
		)
	})
}

func recoverPanics(logger *slog.Logger, next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		defer func() {
			v := recover()
			if v == nil {
				return
			}
			if v == http.ErrAbortHandler {
				panic(v)
			}
			logger.ErrorContext(r.Context(), "panic", "value", v, "path", r.URL.Path, "stack", string(debug.Stack()))
			httpx.Fail(w, http.StatusInternalServerError, "internal", "something went wrong")
		}()
		next.ServeHTTP(w, r)
	})
}

func securityHeaders(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		h := w.Header()
		h.Set("X-Content-Type-Options", "nosniff")
		h.Set("X-Frame-Options", "DENY")
		h.Set("Referrer-Policy", "strict-origin-when-cross-origin")
		next.ServeHTTP(w, r)
	})
}
```

```go
package server

import (
	"context"
	"log/slog"
	"net/http"
	"time"

	"github.com/jackc/pgx/v5/pgxpool"

	"github.com/Nurasick/NUPP/api/internal/catalog"
	"github.com/Nurasick/NUPP/api/internal/httpx"
	"github.com/Nurasick/NUPP/api/internal/storage"
)

const healthTimeout = 2 * time.Second

// Deps are the server's collaborators.
type Deps struct {
	Pool   *pgxpool.Pool
	Files  storage.Storage
	Logger *slog.Logger
}

// New returns the fully wired HTTP handler.
func New(d Deps) http.Handler {
	mux := http.NewServeMux()
	mux.HandleFunc("GET /healthz", healthz(d.Pool))
	catalog.NewHandler(d.Pool, d.Files).Register(mux)
	mux.HandleFunc("/api/", func(w http.ResponseWriter, _ *http.Request) {
		httpx.Fail(w, http.StatusNotFound, "not_found", "no such endpoint")
	})
	return recoverPanics(d.Logger, logRequests(d.Logger, securityHeaders(mux)))
}

func healthz(pool *pgxpool.Pool) http.HandlerFunc {
	return func(w http.ResponseWriter, r *http.Request) {
		ctx, cancel := context.WithTimeout(r.Context(), healthTimeout)
		defer cancel()
		if err := pool.Ping(ctx); err != nil {
			slog.ErrorContext(r.Context(), "health check failed", "err", err)
			httpx.Fail(w, http.StatusServiceUnavailable, "unavailable", "database unreachable")
			return
		}
		httpx.OK(w, map[string]string{"status": "ok"})
	}
}
```

```go
package main

import (
	"context"
	"errors"
	"fmt"
	"log/slog"
	"net/http"

	"os/signal"

	"time"

	"github.com/Nurasick/NUPP/api/internal/db"
	"github.com/Nurasick/NUPP/api/internal/server"
	"github.com/Nurasick/NUPP/api/internal/storage"
)

const shutdownTimeout = 10 * time.Second

func main() {
	logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))
	slog.SetDefault(logger)
	if err := run(logger); err != nil {
		logger.Error("server stopped", "err", err)
		os.Exit(1)
	}
}

func run(logger *slog.Logger) error {
	_ = godotenv.Load() // optional .env for local dev; real env vars win

	cfg, err := config.Load(os.Getenv)
	if err != nil {
		return err
	}
	ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)
	defer stop()

	pool, err := db.Connect(ctx, cfg.DatabaseURL)
	if err != nil {
		return err
	}
	defer pool.Close()
	if err := db.Migrate(ctx, pool); err != nil {
		return err
	}
	files, err := storage.NewLocal(cfg.StorageDir)
	if err != nil {
		return err
	}

	srv := &http.Server{
		Addr:              cfg.HTTPAddr,
		Handler:           server.New(server.Deps{Pool: pool, Files: files, Logger: logger}),
		ReadHeaderTimeout: 5 * time.Second,
		IdleTimeout:       60 * time.Second,
	}
	errCh := make(chan error, 1)
	go func() {
		logger.Info("listening", "addr", cfg.HTTPAddr, "env", cfg.Env)
		errCh <- srv.ListenAndServe()
	}()

	select {
	case err := <-errCh:
		if !errors.Is(err, http.ErrServerClosed) {
			return fmt.Errorf("listen: %w", err)
		}
		return nil
	case <-ctx.Done():
	}
	logger.Info("shutting down")
	shutdownCtx, cancel := context.WithTimeout(context.Background(), shutdownTimeout)
	defer cancel()
	return srv.Shutdown(shutdownCtx)
}
```

```go
	if err != nil {
		t.Fatalf("load spec: %v", err)
	}

		t.Fatalf("spec is invalid: %v", err)

	router, err := gorillamux.NewRouter(doc)
	if err != nil {
		t.Fatalf("build router: %v", err)
	}

	unknown := "6f1c2a43-8a8e-4b7c-9d0e-2f3a4b5c6d7e"
	paths := []string{
		"/healthz",
		"/api/v1/courses",
		"/api/v1/courses?q=zzz&limit=5",
		"/api/v1/courses?limit=abc",

		"/api/v1/offerings/" + unknown + "/materials",
		"/api/v1/materials/" + fx.Material.ID.String(),
		"/api/v1/materials/not-a-uuid",
	}
	for _, path := range paths {
		t.Run(path, func(t *testing.T) {
			req := httptest.NewRequest(http.MethodGet, path, nil)
			rec := httptest.NewRecorder()
			handler.ServeHTTP(rec, req)

			route, params, err := router.FindRoute(req)
			if err != nil {
				t.Fatalf("path not described by spec: %v", err)
			}
			input := &openapi3filter.ResponseValidationInput{
				RequestValidationInput: &openapi3filter.RequestValidationInput{
					Request: req, PathParams: params, Route: route,
				},
				Status: rec.Code,
				Header: rec.Header(),
				Body:   io.NopCloser(bytes.NewReader(rec.Body.Bytes())),
			}
			if err := openapi3filter.ValidateResponse(context.Background(), input); err != nil {
				t.Errorf("status %d response violates spec: %v\nbody: %s", rec.Code, err, rec.Body)
			}
		})
	}
}
```

```go
// Command seed inserts a small demo catalog for local development. It is
// idempotent: if the demo course exists it does nothing.
package main

import (
	"bytes"
	"context"
	"crypto/sha256"
	"encoding/hex"
	"errors"
	"fmt"
	"image"
	"image/color"
	"image/png"
	"log/slog"
	"os"

	"github.com/google/uuid"
	"github.com/jackc/pgx/v5"
	"github.com/joho/godotenv"

	"github.com/Nurasick/NUPP/api/internal/catalog/catalogdb"
	"github.com/Nurasick/NUPP/api/internal/config"
	"github.com/Nurasick/NUPP/api/internal/db"
	"github.com/Nurasick/NUPP/api/internal/storage"
)

func main() {
	if err := run(context.Background()); err != nil {
		slog.Error("seed failed", "err", err)
		os.Exit(1)
	}
}

func run(ctx context.Context) error {
	_ = godotenv.Load()
	cfg, err := config.Load(os.Getenv)
	if err != nil {
		return err
	}
	pool, err := db.Connect(ctx, cfg.DatabaseURL)
	if err != nil {
		return err
	}
	defer pool.Close()
	if err := db.Migrate(ctx, pool); err != nil {
		return err
	}
	files, err := storage.NewLocal(cfg.StorageDir)
	if err != nil {
		return err
	}

	q := catalogdb.New(pool)
	if _, err := q.GetCourseBySlug(ctx, "csci-151"); err == nil {
		slog.Info("demo data already present, nothing to do")
		return nil
	} else if !errors.Is(err, pgx.ErrNoRows) {
		return fmt.Errorf("check existing data: %w", err)
	}

	page, err := demoPNG()
	if err != nil {
		return err
	}
	materialID := uuid.New() // only used to build a unique storage key
	key := fmt.Sprintf("materials/%s/0.png", materialID)
	if err := files.Put(ctx, key, bytes.NewReader(page)); err != nil {
		return fmt.Errorf("store demo file: %w", err)
	}

	tx, err := pool.Begin(ctx)
	if err != nil {
		return fmt.Errorf("begin: %w", err)
	}
	defer tx.Rollback(ctx) //nolint:errcheck // no-op after commit
	if err := insertDemo(ctx, q.WithTx(tx), key, page); err != nil {
		return err
	}
	if err := tx.Commit(ctx); err != nil {
		return fmt.Errorf("commit: %w", err)
	}
	slog.Info("seeded demo catalog", "course", "csci-151")
	return nil
}

func insertDemo(ctx context.Context, q *catalogdb.Queries, key string, page []byte) error {
	dept := "SEDS"
	course, err := q.CreateCourse(ctx, catalogdb.CreateCourseParams{
		Code: "CSCI 151", Slug: "csci-151", Title: "Programming for Scientists and Engineers", Department: &dept,
	})
	if err != nil {
		return fmt.Errorf("create course: %w", err)
	}
	offering, err := q.CreateOffering(ctx, catalogdb.CreateOfferingParams{CourseID: course.ID, Year: 2025, Term: "fall"})
	if err != nil {
		return fmt.Errorf("create offering: %w", err)
	}
	one := int32(1)
	midterm, err := q.CreateAssessment(ctx, catalogdb.CreateAssessmentParams{OfferingID: offering.ID, Kind: "midterm", Number: &one})
	if err != nil {
		return fmt.Errorf("create assessment: %w", err)
	}
	material, err := q.CreateMaterial(ctx, catalogdb.CreateMaterialParams{
		OfferingID: offering.ID, AssessmentID: &midterm.ID,
		Title: "Midterm 1 questions (demo)", Type: "questions", Description: "Demo page generated by cmd/seed",
	})
	if err != nil {
		return fmt.Errorf("create material: %w", err)
	}
	sum := sha256.Sum256(page)
	if _, err := q.CreateMaterialFile(ctx, catalogdb.CreateMaterialFileParams{
		MaterialID: material.ID, StorageKey: key, MimeType: "image/png",
		SizeBytes: int64(len(page)), Sha256: hex.EncodeToString(sum[:]), Position: 0,
	}); err != nil {
		return fmt.Errorf("create material file: %w", err)
	}
	return nil
}

func demoPNG() ([]byte, error) {
	img := image.NewRGBA(image.Rect(0, 0, 400, 200))
	fill := color.RGBA{R: 30, G: 64, B: 175, A: 255}
	for y := range 200 {
		for x := range 400 {
			img.Set(x, y, fill)
		}
	}
	var buf bytes.Buffer
	if err := png.Encode(&buf, img); err != nil {
		return nil, fmt.Errorf("encode demo png: %w", err)
	}
	return buf.Bytes(), nil
}
```
